# P0 Deep Mode — Category-Specific Questions

## Category Detection

After asking the initial problem description, classify into: **bug**, **feature**, or **refactor**.

## Bug Questions

1. "현재 어떤 동작이 발생하나요? (What is the current behavior?)"
2. "기대하는 동작은 무엇인가요? (What is the expected behavior?)"
3. "언제부터 이 문제가 발생했나요? 관련된 변경사항이 있나요? (When did this start? Any related changes?)"
4. "재현 방법을 알려주세요. (How can we reproduce it?)"
5. "결과를 어떻게 검증하나요? (How do we verify the fix?)"

## Feature Questions

1. "달성하고 싶은 결과가 무엇인가요? (What outcome do you want to achieve?)"
2. "완료 조건은 무엇인가요? (What does 'done' look like?)"
3. "이 기능의 범위를 어디까지로 제한할까요? (What is the scope boundary?)"
4. "제약 조건이 있나요? (성능, 호환성, 기존 API 등) (Any constraints? Performance, compatibility, existing APIs, etc.)"
5. "결과를 어떻게 검증하나요? (How do we verify success?)"

## Refactor Questions

1. "현재 코드의 어떤 점이 문제인가요? (What's wrong with the current code?)"
2. "리팩토링 후 어떤 상태가 되어야 하나요? (What should the code look like after refactoring?)"
3. "기존 동작 중 반드시 보존해야 할 것은 무엇인가요? (What existing behavior must be preserved?)"
4. "제약 조건이 있나요? (Any constraints?)"
5. "결과를 어떻게 검증하나요? (How do we verify success?)"
